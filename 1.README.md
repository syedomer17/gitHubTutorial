# 🚀 Git & GitHub for Beginners

A simple guide to understand **Git** (version control) and **GitHub** (cloud collaboration).

---

## 🔹 What is Git?
- Git is like a **time machine** for your code.
- It keeps **snapshots** (called commits) of your project.
- You can go **back in time**, compare changes, or restore old versions.

👉 **Git = version control system (works on your computer).**

---

## 🔹 What is GitHub?
- GitHub is like **Google Drive** but for code.
- Instead of keeping your Git snapshots only on your laptop, you can **push them online**.
- Makes it easy to:
  - Share code 👨‍💻👩‍💻
  - Work together as a team
  - Keep your code safe in the cloud

👉 **GitHub = a website to store & collaborate on Git projects.**

---

## 🔹 Why use Git & GitHub?
1. **Track changes** – Know who changed what and when.  
2. **Undo mistakes** – Go back if something breaks.  
3. **Work in teams** – Multiple people can work on the same project without overwriting.  
4. **Backup** – Code is safe in the cloud.  
5. **Portfolio** – GitHub shows your projects to the world (great for jobs/internships).  

---

## 🔹 When to use?
- **Solo projects** – Even if you’re alone, Git saves you from mistakes.  
- **Team projects** – Must-have for collaboration.  
- **Open source** – If you want to contribute to others’ code.  
- **Any coding project** – Small or big, Git helps.  

---


# ✅ Quick Analogy
- **Git** = your **diary of changes** (on your computer).  
- **GitHub** = the **library where you publish your diary**, so others can read or contribute.
