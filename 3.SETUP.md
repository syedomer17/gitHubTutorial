

# 🛠️ Git and GitHub Setup  Guide

This guide explains how to install Git, configure it, set up SSH keys, and use GitHub with two methods.

## 🔹 To Install Git

### On Ubuntu (WSL)
```bash
sudo apt update && sudo apt upgrade
sudo apt install git
git --version   # Check if Git is installed
```

### On MacBook (Apple)
```bash
brew install git
git --version   # Check if Git is installed
```

## 🔑 SSH Keys Setup Guide

1. Open your terminal.  
2. Go to the home directory:
   ```bash
   cd
   ```  
3. Generate SSH keys:
   ```bash
   ssh-keygen -t ed25519 -C "syedomerali2006@gmail.com"
   ```  
   Press **Enter 4 times** (accept default locations and settings).  

4. Go to the `.ssh` directory:
   ```bash
   cd .ssh
   ls
   ```  
   You will see:  
   - `id_ed25519` (private key)  
   - `id_ed25519.pub` (public key)  

5. View and copy the public key:
   ```bash
   cat id_ed25519.pub
   ```  

6. Go to **GitHub → Profile → Settings → SSH and GPG Keys**.  
   - Click **New SSH Key**.  
   - Add a title (e.g., `23rd May 2025`).  
   - Paste the public key into the box.  
   - Click **Save**.  

7. Test the connection:
   ```bash
   ssh -T git@github.com
   ```  
   Type **yes** when prompted.  

✅ Success Message:  
```
Hi syedomer17! You've successfully authenticated, but GitHub does not provide shell access.
```

# 🔹 Two Ways to Use GitHub

## 📌 Method I: Starting a New Project (No Code Yet)
(Basically you just got an idea and want to start fresh.)

1. Go to [GitHub](https://github.com).  
2. Profile photo → **Your repositories**.  
3. Click **New Repository**.  
4. Name your repo (use camelCase: `myProject`, `zomatoProject`)  and add a description
5. Select **Public or Private**.  
6. ✅ Check "Add a README.md".  
7. Click **Create Repository**.  
8. Copy the **SSH URL**.  
9. Clone it:
   ```bash
   cd
   git clone git@github.com:suhailroushan13/globalTest.git
   cd yourRepoFolder
   ```  
10. Create folder & file:
    ```bash
    mkdir folderName
    touch file.txt
    ```  
11. Push code:
    ```bash
    git add .
    git commit -m "YOUR MESSAGE"
    git branch   # shows main or master
    git push origin main   # or master
    ```  
12. Check your repo on GitHub  🎉  

---

## 📌 Method II: Already Have a Codebase
(You already have files/folders you want to push.)

1. Have your project ready (e.g., `netflixProject`).  
   ⚠️ Empty folders won’t be pushed.  

2. Go to GitHub → `Create new repository with same name as your project`.  
   - **Do NOT check "Add README.md"**.  

3. Copy the **SSH URL** from the  repository page.  
4. Go to your project folder:
   ```bash
   cd
   cd netflixProject
   ```  
5. Initialize Git:
   ```bash
   git init
   ```  
6. Add remote origin:
   ```bash
   git remote add origin git@github.com:suhailroushan13/globalTest.git
   ```  
7. Stage all files:
   ```bash
   git add .
   ```  
8. Commit changes:
   ```bash
   git commit -m "Initial commit"
   ```  
9. Push code:
   ```bash
   git branch   # shows main or master
   git push origin main   # or master
   ```  
10. Check your repository on GitHub 🎉
